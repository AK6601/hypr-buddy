## shiro.png — generation prompt

Create ONE beautifully polished full body anime chibi young adult techie companion, 3-head-tall proportions, teal and deep purple short layered hair, small translucent cyan visor resting above the eyes so the warm expressive eyes are visible, charcoal oversized techwear jacket with restrained teal and lavender accents, dark shorts over opaque leggings, chunky sneakers. Friendly relaxed standing pose, arms relaxed slightly away from body, feet together, frontal view, subtle smile. Crisp professional hand-drawn anime game illustration with clean silhouette and readable shapes at 200px, soft cel shading, restrained detail. Center entire character in a square canvas with 8 percent transparent padding on all sides. Actual transparent alpha background, no ground, no shadow outside character, no text, no panels, no duplicates, no sprite sheet. This single stable illustration will be animated procedurally to avoid inconsistent generated frame anatomy.

## shiro-blink.png — edit prompt

Use case: identity-preserve. Edit target is Shiro desktop companion. Change ONLY her eyes to gently closed happy curved eyelids for a blink animation. Every other pixel, face outline, mouth, hair, pose, hands, outfit, body size, canvas size, and character registration MUST stay identical. Keep actual transparent alpha background. One full character, no text or sheets.

The edit used shiro.png as its reference. The renderer uses only the registered eye
patch of the blink variant to avoid moving the rest of the character between frames.
`../previews/shiro.png` is an animated PNG generated by the Rust renderer, not an
independently generated animation or a screenshot of the desktop.
